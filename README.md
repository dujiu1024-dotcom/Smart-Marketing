# AI 门店运营官

## 多文件 Demo
入口：`demo/index.html`

文件结构：
- `demo/index.html`：应用入口
- `demo/styles.css`：设计系统与响应式样式
- `demo/data.js`：演示种子数据（含明确标记的热点机会样例）
- `demo/store.js`：本地状态与持久化
- `demo/app.js`：门店端页面、路由、营销流程与交互
- `demo/admin.js`：平台管理端页面与操作

## 本地运行
ES Module 需要通过 HTTP 服务运行，不建议直接双击 HTML 文件。

在仓库根目录执行：

```bash
python -m http.server 8080
```

浏览器访问：

```text
http://localhost:8080/demo/
```

## Demo 交互范围
- 门店端：AI 营销、热点机会工作台（关键词/分类/状态筛选、过期识别、非实时演示样例）、独立需求理解、营销任务、幂等策略确认、平台独立文案审核、文案整改与历史版本对比/恢复、图片双模式示意预览与历史版本恢复、渠道适配、版本绑定质检、冻结发布内容包。
- 经营效果：独立模块；默认无数据状态，只有主动加载时才展示标注为演示数据的样例。
- 门店资料：门店档案、商品服务、活动优惠、品牌规范、客群经营、知识库、素材库、门店渠道账号。
- 平台管理端：运营总览、门店管理（含用户）、AI 运行监控、门店管理内的模型配置、AI 能力配置、用量与成本、审计日志和系统配置；第一轮已完成页面范围收敛。
- 状态与记录保存在当前浏览器 localStorage；当前任务定位可刷新恢复，旧数据读取时执行字段迁移。单文件上传限制 1 MB，并在上传前检查本地存储余量。

## 真实服务边界
当前版本是前端产品交互原型：
- AI 文案生成/整改使用模拟逻辑。
- 图片生成/二次改造使用模拟适配器，展示本地 SVG 示意预览，不是真实图像模型结果。
- 渠道 OAuth、草稿保存、真实发布未连接。
- 真实热点采集、平台表现数据及经营效果数据服务尚未连接；当前未确认 POS、团购核销、CRM、会员等系统接入。
- 管理端不具备生产环境身份认证、服务端门店级访问控制、密钥托管和防篡改审计；未接入的安全/能力开关为禁用状态。

所有模拟能力均应按演示状态理解，不代表真实服务已经接通。

## 二次优化记录（2026-11-10）

- 商品新增/编辑后默认待确认；商家显式确认后才可作为营销事实依据。
- 本地存储失败时恢复最近一次成功持久化快照，并提示保存失败。
- 数据层统一补齐核心业务集合并标记 schemaVersion。
- 图片工作室补齐种子素材 SVG 演示源图；图片整改继承原画幅，风格和指令影响模拟预览。
- 旧版数据连接中心虽有本地表单逻辑，但不属于已确认产品范围，已从门店与管理端界面移除。
- 本轮仍需真实浏览器端到端验收；SVG 图片仅为演示占位，不代表真实图像模型结果。


## 产品范围纠偏（2026-11-10）

- 热点采集与门店匹配是 AI 营销核心能力：当前 Demo 已提供热点机会工作台、演示匹配理由和采纳创建任务链路；真实热点采集、动态匹配、去重和来源链接仍未接入。
- 门店是管理主体；用户管理位于门店详情；模型与 API Key 按门店绑定。
- 不建设租户管理、角色管理、工单、后台素材审核、后台渠道/数据接入中心或独立归因后台。
- 任务监控与 AI 运行记录合并为 AI 运行监控，按营销任务查看业务进度并下钻 AI 调用。
- 具体修订以产品设计 v1.6、UI/UX 审查和验收矩阵 v1.4 为准。
