# AI 门店运营官

AI 门店运营官是一个以经营效果为核心的门店营销执行平台产品原型。

## 多文件 Demo
入口：`demo/index.html`

文件结构：
- `demo/index.html`：应用入口
- `demo/styles.css`：设计系统与响应式样式
- `demo/data.js`：演示种子数据
- `demo/store.js`：本地状态与持久化
- `demo/app.js`：门店端页面、路由、营销流程与交互
- `demo/admin.js`：平台管理端页面与操作

## 本地运行
ES Module 需要通过 HTTP 服务运行，不建议直接双击 HTML 文件。

在仓库根目录执行：

```bash
python -m http.server 8080
```

浏览器访问：

```text
http://localhost:8080/demo/
```

## Demo 交互范围
- 门店端：AI 营销、营销任务、策略确认、平台独立文案审核、图片双模式生产、图片独立审核、渠道适配、质检、发布内容包。
- 经营效果：独立模块；默认无数据状态，只有主动加载时才展示标注为演示数据的样例。
- 门店资料：门店档案、商品服务、活动优惠、品牌规范、客群经营、知识库、素材库、渠道账号、数据连接。
- 平台管理端：运营总览、租户、门店、用户、角色权限、任务监控、AI 运行、模型路由、提示词、工作流、素材审核、渠道、数据接入、归因、成本、工单、审计和系统配置。
- 状态与记录保存在当前浏览器 localStorage，可刷新恢复。

## 真实服务边界
当前版本是前端产品交互原型：
- AI 文案生成/整改使用模拟逻辑。
- 图片生成/二次改造使用模拟适配器，不会生成真实图像模型结果。
- 渠道 OAuth、草稿保存、真实发布未连接。
- POS、订单、CRM、平台表现数据未连接。
- 管理端不具备生产环境身份认证、服务端 RBAC、租户隔离、密钥托管和防篡改审计。

所有模拟能力均应按演示状态理解，不代表真实服务已经接通。
