## 一、页面覆盖

| 产品能力 | Demo 页面/模块 | 当前实现 | 真实服务边界 |
|---|---|---|---|
| AI 营销目标输入 | AI 营销工作台 | 结构化目标、类型、商品、客群、日期、预算、动作、渠道输入 | 策略由本地演示逻辑构造 |
| 经营上下文 | AI 营销 / 策略确认 | 展示门店、商品、客群、经营限制与来源 | 未接外部热点、POS 历史经营数据 |
| 策略确认 | 任务详情 / 策略 | 可编辑目标、指标、场景、卖点、渠道、活动、素材、风险 | 模拟 AI 决策 |
| 文案生成与审核 | 文案工作室 | 多渠道独立文案、标题/正文/标签、保存、通过、整改、上传 TXT/MD、历史版本和审核事件 | AI 生成/整改为模拟逻辑 |
| 信息图生产 | 图片工作室 | 模式、商品、画幅、风格、标题、指令、版本和审核 | 模拟适配器，不是真实图像生成 |
| 原图二次改造 | 图片工作室 | 素材选择、源图关系、指令、源图不覆盖 | 图像改造服务未连接 |
| 商家图片上传 | 图片工作室 / 素材库 | 本地文件读取、预览、作为新版本保存、独立审核 | 当前浏览器本地存储，单文件限制 2 MB |
| 渠道适配 | 渠道工作区 | 小红书、抖音、快手、视频号独立预览字段 | 账号 OAuth 未连接，规格规则为原型配置 |
| 质量检查 | 质检工作区 | 根据审核状态、商品确认、渠道连接执行本地阻断规则 | 未接 OCR、模型审核和平台规则实时服务 |
| 发布确认 | 发布工作区 | 校验目标渠道文案和图片审核，保存待人工发布包 | 未向真实平台发起发布 |
| 营销任务管理 | 任务列表 / 任务详情 | 搜索筛选、复制、归档、事件时间线、独立状态 | 任务数据保存在当前浏览器 |
| 经营效果 | 独立效果中心 | 默认空状态、观察窗口、明确标注的演示样例 | 未接真实平台数据、POS、CRM、归因 |
| 门店资料 | 门店资料中心 | 档案、商品、活动、品牌、客群、知识、素材、渠道、数据连接 | 地址地图校验、外部数据连接未接 |
| 平台运营后台 | 管理端 18 个模块 | 租户、门店、用户、角色、任务、AI 运行、模型、提示词、工作流、素材、渠道、数据、归因、成本、工单、审计、系统配置 | 无生产认证、RBAC 服务、密钥托管、真实账单与后端 API |

## 二、关键业务规则验证

| 规则 | 验证方式 | 当前结果 |
|---|---|---|
| 经营效果不属于营销任务执行步骤 | 检查任务详情 tabs 和效果中心独立路由 | 通过 |
| 效果数据默认不伪造 | 首次进入效果中心应显示空状态 | 通过 |
| 演示样例必须显式加载并标注 | 点击“加载明确标注的演示数据” | 通过 |
| 文案按渠道独立审核 | 小红书、抖音分别审核，状态互不替代 | 通过 |
| 图片审核独立于文案审核 | 图片单独通过/整改，文案状态不被替代 | 通过 |
| 图片生产前需目标渠道文案通过 | 未全部通过时生成按钮应阻断 | 通过（逻辑检查） |
| 发布包需目标渠道文案和图片均通过 | 未满足条件时阻断保存发布包 | 通过（交互模拟） |
| 文案变化使下游图片需复核 | 已有图片后修改文案 | 通过（逻辑检查） |
| 原图与衍生图分离 | 图片版本保存 sourceId/sourceName | 通过 |
| 外部渠道未连接不显示发布成功 | 保存内容包后显示待人工发布 | 通过 |
| 商家上传内容不会自动通过 | 上传文案/图片后进入待审核 | 通过 |
| 任务刷新后状态可恢复 | localStorage 本地持久化 | 已实现，需浏览器实测 |

## 三、工程检查

- JavaScript 模块语法检查：通过。
- 门店端、任务、效果中心、门店资料 9 个分区、管理端 18 个路由，共 31 个页面路由渲染烟雾测试：通过。
- 模拟端到端交互：目标渠道文案分别通过 → 创建模拟图片版本 → 图片审核通过 → 保存待人工发布包：通过。
- 页面实际浏览器点击、不同浏览器 localStorage 配额、窄屏视觉和真实文件上传：尚需人工浏览器验收，不能将路由渲染烟雾测试等同于完整浏览器测试。

## 四、当前明确未接入的生产能力

1. 真实 LLM 策略、文案生成与整改。
2. 真实图片生成、图片编辑、OCR 和视觉事实检查。
3. 小红书、抖音、快手、视频号 OAuth、草稿保存、发布与回执。
4. 平台内容表现、POS、订单、团购核销、CRM、会员数据连接。
5. 真实归因计算、成本计费和告警。
6. 生产级登录认证、租户隔离、RBAC 服务端鉴权、密钥托管和防篡改审计。
7. 服务端文件存储、病毒扫描、版权审核和素材 CDN。

这些属于真实后端与第三方适配器接入工作，不应通过前端假数据伪装为已完成。
