# Demo 与产品设计验收追踪矩阵

版本：v1.4  
对应产品基线：[PRODUCT_DESIGN.md v1.6](PRODUCT_DESIGN.md)  
对应 UI/UX 审查：[UX_AUDIT_AND_REDESIGN.md](UX_AUDIT_AND_REDESIGN.md)

> 本矩阵明确区分产品要求、当前 Demo 实现和生产服务边界。未实现的能力必须列为缺口，不得用静态展示或模拟数据宣称已完成。

## 一、产品页面与功能覆盖

| 产品能力 | 目标页面/模块 | 当前 Demo 状态 | 真实服务边界/缺口 |
|---|---|---|---|
| AI 营销需求理解 | AI 营销 / 需求理解 | 已增加独立需求理解页，可编辑目标、类型、商品、客群、动作与日期；当前为本地规则/表单演示，未接真实 AI 理解 | 需实现结构化理解、缺失信息提示、商家修正 |
| 热点采集 | AI 营销 / 热点机会 | 已增加热点机会工作台与预置演示样例；真实采集源、原始链接和实时数据尚未接入 | 需接入公开趋势来源或采集服务；来源、采集时间、地域、有效期必须可追溯 |
| 热点与门店匹配 | AI 营销 / 热点机会、策略确认 | 已展示预置匹配商品、客群、场景、理由与风险；匹配评分为静态演示数据，尚无真实匹配引擎 | 需结合门店、商品、客群、场景、品牌和任务目标评估相关性 |
| 热点内容营销 | 从热点创建营销任务 | 已支持采纳/忽略/暂缓；采纳可创建营销任务并保存热点快照，待浏览器验收 | 采纳热点后需创建营销任务，保存热点引用、匹配理由和内容方向 |
| 策略确认 | 任务详情 / 策略确认 | 本地模拟策略编辑、保存、确认 | 非真实 LLM 策略生成 |
| 文案生成与审核 | 文案工作室 | 多渠道独立审核、整改、历史版本、对比与恢复 | 整改逻辑为本地模拟，不是真实 LLM |
| 图片制作与审核 | 图片工作室 | 信息图/原图改造为 SVG 示意预览；版本与审核状态独立 | 未连接真实图像生成/编辑服务 |
| 渠道适配 | 营销任务 / 渠道适配 | 有渠道内容字段和预览 | OAuth、平台规则实时校验和真实发布未连接 |
| 质量检查 | 质量检查 | 本地规则检查、质检指纹和发布阻断 | 未接 OCR、实时平台规则和生产模型质检 |
| 发布确认 | 发布确认 | 审核门槛、最终确认、冻结发布包 | 仅待人工发布，不向平台真实发布 |
| 营销任务 | 营销任务列表/详情 | 搜索、筛选、复制、归档、事件记录 | 当前数据保存在浏览器本地 |
| 经营效果 | 独立经营效果中心 | 默认空状态；可加载明确标记的演示样例 | 未接真实平台表现或门店交易数据；不默认接 POS/CRM |
| 门店资料 | 门店资料中心 | 档案、商品、活动、品牌、客群、知识、素材、渠道账号；旧数据连接入口已移除 | 需按最终范围移除未确认的数据连接模块及外部系统示例 |
| 平台管理端 | 运营总览、门店管理、AI 运行监控、AI 能力配置、用量成本、审计/系统配置 | 已重构为运营总览、门店管理（含用户）、AI 运行监控、AI 能力配置、用量成本、审计和系统配置；遗留种子数据/旧处理代码仍需清理 | 必须按产品基线收敛；门店用户和模型配置下沉门店详情 |

## 二、热点采集与匹配专项验收（P0）

| ID | 验收项 | 验收规则 | 当前状态 |
|---|---|---|---|
| HOT-01 | 热点来源可追溯 | 每条热点包含来源、原始链接/来源标识、采集时间、地域、有效窗口 | 部分实现：演示来源、采集时间、地域和有效期可见；原始链接/真实来源未接入 |
| HOT-02 | 热点去重与时效 | 重复热点合并；过期热点降权或失效，不进入正常推荐 | 未实现 |
| HOT-03 | 门店相关性匹配 | 结合门店行业/地域、商品、客群、场景、品牌规范和经营限制 | 部分实现：静态演示匹配结果可见；真实动态匹配算法未实现 |
| HOT-04 | 推荐理由可解释 | 展示匹配商品、客群、场景、渠道、时效和风险，不以热度单一排序 | 部分实现：展示商品、客群、场景、内容方向、时效和风险；渠道推荐仍需完善 |
| HOT-05 | 不匹配过滤 | 不相关、过期、风险过高热点不推荐；允许返回“当前无适合热点” | 未实现 |
| HOT-06 | 内容营销建议 | 匹配热点生成选题角度、内容形式、标题方向、渠道和所需素材 | 部分实现：展示内容角度与形式；标题方向、渠道和素材清单未完整生成 |
| HOT-07 | 一键创建任务 | 采纳热点后创建营销任务，保存热点 ID/快照和匹配理由 | Demo 已实现：创建任务并保存热点快照；待浏览器验收 |
| HOT-08 | 热点数据状态 | 采集源不可用时展示未连接、最后成功时间和失败原因；不伪造实时热点 | 部分实现：明确标记非实时样例和未连接；最后成功时间/失败原因待接入 |
| HOT-09 | 经营效果回流 | 有实际数据后分析热点内容表现，未达到观察窗口不生成结论 | 未实现 |

| ADM-10 | 不设工单系统 | 不出现工单导航、数据和流程 | Demo 已移除工单页面、旧工单种子和旧处理代码 |

## 六、验证边界与未接入服务

- JavaScript 静态语法检查通过，不等于真实浏览器 ESM、路由和交互验收通过。
- 真实热点采集、去重、地域/行业识别和匹配服务尚未接入。
- 真实 LLM 策略/文案生成与图片生成/编辑服务尚未接入。
- 平台 OAuth、草稿保存、真实发布和平台表现数据尚未接入。
- 当前未确认 POS、团购核销、CRM、会员等第三方系统接入；不得把它们写成产品既定能力。
- 生产级登录、门店级服务端访问控制、API Key 加密托管、文件存储和审计防篡改尚未实现。
- 浏览器端到端、窄屏布局、数据迁移和文件上传测试需单独记录结果。
