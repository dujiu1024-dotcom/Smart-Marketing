## 一、页面与功能覆盖

| 产品能力 | Demo 页面/模块 | 当前实现 | 真实服务边界 |
|---|---|---|---|
| AI 营销目标输入 | AI 营销工作台 | 结构化目标、类型、商品、客群、日期、预算、动作、渠道输入 | 策略由本地演示逻辑构造 |
| 经营上下文 | AI 营销 / 策略确认 | 展示门店、商品、客群、经营限制与来源 | 未接外部热点、POS 历史经营数据 |
| 策略确认 | 任务详情 / 策略 | 待确认/已确认状态；重复确认幂等；策略修改后重新确认并为目标渠道创建新文案版本 | 策略内容为模拟逻辑 |
| 文案生成与审核 | 文案工作室 | 多渠道独立审核；按修改要求生成新正文/标题；保存完整历史内容；版本对比与恢复；商家文案上传形成新版本 | 整改规则为本地模拟，不是真实 LLM |
| 信息图生产 | 图片工作室 | 独立信息图模式；按画幅生成可见 SVG 示意预览；版本与审核状态独立 | SVG 为明确标注的示意预览，不是真实图像生成 |
| 原图二次改造 | 图片工作室 | 源素材必须存在且可使用；保存源图 ID、名称和可用源图预览；显示模拟结果对比 | 图像改造服务未连接 |
| 图片版本管理 | 图片工作室 | 新版本、整改、恢复历史版本；恢复后重新审核；源图不可覆盖 | 本地演示状态 |
| 商家图片上传 | 图片工作室 / 素材库 | 本地文件读取、预览、作为新版本保存、独立审核 | 浏览器 localStorage；单文件限制 1 MB，并预估剩余存储空间 |
| 渠道适配 | 渠道工作区 | 小红书、抖音、快手、视频号独立预览字段 | OAuth 未连接，规格规则为原型配置 |
| 质量检查 | 质检工作区 | 检查全部目标渠道文案、当前图片、商品事实、源素材；质检结果绑定内容指纹 | 未接 OCR、模型审核和平台规则实时服务 |
| 发布确认 | 发布工作区 | 必须审核全部目标渠道文案和当前图片；必须质检通过且指纹新鲜；必须勾选最终确认并填写说明；冻结内容快照 | 仅保存本地待人工发布包，不向平台发布 |
| 营销任务管理 | 任务列表 / 任务详情 | 搜索筛选、复制、归档、事件记录；当前任务 ID 刷新后恢复 | 任务数据保存在当前浏览器 |
| 经营效果 | 独立效果中心 | 默认空状态、观察窗口、明确标注的演示样例 | 未接真实平台数据、POS、CRM、归因 |
| 门店资料 | 门店资料中心 | 档案、商品、活动、品牌、客群、知识、素材、渠道、数据连接；商品素材 ID 统一归一为数组 | 外部数据连接未接 |
| 平台运营后台 | 管理端 18 个模块 | 租户、门店、用户、角色、任务、AI 运行、模型、提示词、工作流、素材、渠道、数据、归因、成本、工单、审计、系统配置 | 无生产认证、RBAC 服务、密钥托管、真实账单与后端 API |

## 五、代码级验证与浏览器验收状态

本轮修复后执行以下代码级检查：

- `demo/app.js`、`demo/admin.js`、`demo/store.js`、`demo/data.js` JavaScript 语法解析：通过。
- 静态检查关键业务实现：质检指纹、发布确认、内容快照、策略幂等、文案版本恢复、图片版本恢复、任务 ID 持久化、商品素材数组迁移：已逐项检查。
